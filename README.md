# 留学跟进顾问

个人项目。用合成客户和合成政策，复现「销售跟进会断」这件事里的记忆、转人工和评测。

公司项目里的原型、需求原稿、账号和客户数据不在这个仓库里。

## 这个周末要交出的东西

1. 一页范围：做什么、不做什么。
2. 一条可重放轨迹：读了哪条记忆、调了哪个工具、最后是回答还是转人工。
3. 记忆的三种行为：写入、召回、冲突时两条都留。
4. 18 条手写用例，六类各 3 条。
5. 同一套题的两版对比：全量历史，对比只注入召回到的事实。
6. 一个讲透的失败：预算从 30 万改成 15 万，仍按旧预算说话。
7. 一张成本便签：模型名、平均 token、单价查看日期、一轮跟进几次调用。
8. 十分钟讲解：问题、方案、证据、取舍、边界。

范围细节见 [docs/scope.md](docs/scope.md)。
